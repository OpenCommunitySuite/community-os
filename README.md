
# Community OS

> Open Source платформа для управления сообществами собственников.

---

## Что такое Community OS?

Community OS — это открытая модульная платформа, предназначенная для автоматизации деятельности сообществ собственников.

Проект создаётся как универсальное решение, которое сможет использоваться различными типами организаций:

- 🌳 садовые товарищества;
- 🏢 ОСББ;
- 🏘️ коттеджные посёлки;
- 🚗 гаражные кооперативы;
- 🅿️ парковочные кооперативы;
- 🏠 другие объединения собственников.

Вместо создания отдельных программ для каждого типа организаций разрабатывается единая платформа с возможностью подключения специализированных модулей.

---

## Цели проекта

Community OS должна объединить в одной системе:

- учёт объектов и собственников;
- лицевые счета;
- начисления и платежи;
- учёт коммунальных ресурсов;
- работу с должниками;
- документооборот;
- новости и объявления;
- личный кабинет собственника;
- онлайн-голосования;
- обращения жителей;
- управление имуществом сообщества;
- взаимодействие с бухгалтерскими системами;
- другие функции, необходимые для управления сообществом.

---

## Основные принципы

Проект строится на следующих принципах:

- Open Source;
- Documentation First;
- модульная архитектура;
- поддержка SaaS и Self-Hosted;
- мультиязычный пользовательский интерфейс;
- открытые интерфейсы интеграции;
- прозрачность принимаемых архитектурных решений.

## Язык проекта

- Рабочий язык проектирования — **русский**.
- Основной язык пользовательского интерфейса — **украинский**.

## Как будет разрабатываться проект

Проект создаётся по принципу **Documentation First**.

Каждая новая возможность проходит следующие этапы:

1. обсуждение;
2. описание бизнес-процесса;
3. принятие архитектурного решения;
4. подготовка технического задания;
5. разработка;
6. тестирование;
7. включение в релиз.
