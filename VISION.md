# Community OS

## Статус документа

Draft (Черновик)

## Назначение

Этот документ определяет видение (Vision) проекта Community OS.

Проект находится на стадии формирования концепции. На данном этапе не ведётся разработка программного кода. Основной целью является описание бизнес-процессов, архитектурных принципов и требований к будущей платформе.

Настоящий документ является основой для всей дальнейшей документации проекта.
