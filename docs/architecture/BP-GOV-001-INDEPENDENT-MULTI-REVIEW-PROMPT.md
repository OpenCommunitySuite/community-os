# Задание на независимое рецензирование BP-GOV-001

Проведи независимое предметно-архитектурное рецензирование приложенного пакета Markdown `BP-GOV-001-INDEPENDENT-MULTI-REVIEW-PACKAGE.md`.

Контекст: Community OS — универсальная платформа с открытым исходным кодом для управления сообществами собственников. Первое внедрение — садовое товарищество, но фундаментальная модель не должна быть привязана только к нему.

Важно:

- не проектируй код, базу данных, программный интерфейс (API) или пользовательский интерфейс;
- не подстраивай предметную модель под удобство программной реализации;
- не принимай предложения из черновика автоматически;
- ищи противоречия с уже принятыми предметными и архитектурными принципами;
- отдельно проверь необходимость и границы факта **«Реализация права голоса»** и **«Результат подсчёта офлайн-части»**;
- отдельно проверь защиту анонимности, включая возможность косвенного восстановления связи участника с выбором;
- отдельно оцени критическое замечание: отсутствие определённой предметной модели анонимного электронного выбора при обработке средствами самой Community OS;
- сравни варианты: отложить собственное анонимное электронное голосование за пределы первого внедрения либо уже сейчас вводить новое предметное понятие;
- проверь, не отождествляются ли выдача бюллетеня, участие, реализация права голоса и фактическое волеизъявление;
- проверь бюллетень с несколькими вопросами, бумажную и электронную формы;
- проверь правила конфликтов и изменения голоса при использовании разных способов подачи;
- оцени, достаточно ли точечных исправлений без пересмотра общей предметной концепции.

Классифицируй замечания по существенности: **критическое / существенное / незначительное / примечание** (в исходном пакете: BLOCKER / MAJOR / MINOR / NOTE).

Ответ верни **в формате Markdown**, сохранив структуру, заданную в пакете рецензирования. Если интерфейс позволяет получить отдельный файл, сформируй файл `.md` с результатом.

Не считай внутреннюю рецензию источником истины: это лишь позиция автора черновика, которую необходимо критически проверить.
