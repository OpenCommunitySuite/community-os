Проведи независимый предметно-архитектурный review приложенного Markdown-пакета `BP-GOV-001-INDEPENDENT-MULTI-REVIEW-PACKAGE.md`.

Важно:

- не проектируй код, БД, API или UI;
- не подстраивай предметную модель под удобство реализации;
- не принимай предложения Draft автоматически;

- отдельно проверь необходимость и границы Voting Right Exercise и Result of Offline Count;

- отдельно оцени BLOCKER native online Anonymous choice-side referent;

Используй severity: BLOCKER / MAJOR / MINOR / NOTE.

Ответ верни **в Markdown**, строго в формате, заданном в review package. Если интерфейс позволяет скачать файл, сформируй отдельный `.md` файл результата.

Не считай внутренний review источником истины: это только позиция автора Draft, которую нужно критически проверить.
