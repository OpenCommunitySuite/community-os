# I‑2. Ручные дневные и ночные показания электроэнергии

Статус: проект для закрытого синтетического стенда. Основания — ADR‑007, ADR‑012, ADR‑015, ADR‑018, BP‑READING‑001 и Implementation Baseline.

При регистрации прибора оператор явно выбирает один суммарный регистр или два регистра «День» и «Ночь» в кВт·ч. Режим фиксируется при создании прибора. Существующие приборы сохраняют суммарный регистр и исходную историю. В этом сценарии замена сохраняет режим предыдущего прибора. Изменение режима при замене требует отдельного сценария.

Оператор явно указывает канал по обозначению регистра на приборе. Соответствие T1/T2 и финансовым тарифным зонам не определяется автоматически. Сервер проверяет принадлежность канала прибору, действующую установку на дату измерения и права признания. Для каждого канала отдельно проверяются дневное совпадение, конфликт и накопительная последовательность. Два показания разных каналов за один день допустимы. Совпадение канала, даты и значения возвращает результат «уже записано» с исходным показанием. Старый запрос без канала сохраняет значение `total` для суммарного прибора. Допуск и признание сохраняют выбранный канал и сведения об операторе.

Разница соседних показаний рассчитывается внутри канала и установки. Для двух непересекающихся регистров одинаковой единицы и масштаба сводная оценка формируется только для совпадающих дат начала и конца соседних интервалов обоих каналов. Запоздалое промежуточное показание может изменить разбиение и убрать ранее видимую сводную оценку. При отсутствии сопоставимого интервала интерфейс показывает отдельные значения и объясняет, почему сводная оценка отсутствует. Пустой канал не подменяется нулём. Ставки, начисления и граничные показания при замене остаются за рамками этой поставки.

Приёмка на синтетическом стенде включает два канала в одни даты, раздельные разницы и сводную оценку, несовпадающие интервалы, конфликт в одном канале, отказ для неподдерживаемого канала, изоляцию сообществ, CSRF и отзыв права.
