# I‑2. Пакетный импорт показаний электроэнергии

Первый сценарий проверяется на синтетическом стенде в рамках ADR‑007, ADR‑011, BP‑READING‑001 и проекта BP‑READING‑002. Для импорта выбран шаблон CSV с заголовком `installation_id,measured_on,channel,value_kwh`. Он использует внутренний UUID уже зарегистрированной установки. Сопоставление внешних идентификаторов приборов потребует отдельного контракта источника. UUID точки, номер участка и обозначение прибора сами по себе не определяют установку.

Договорённость для шаблона — UTF‑8, разделитель запятая, одна запись на строку, без кавычек, дата `yyyy-MM-dd`, регистр `total`, `day` или `night`, исходное накопительное значение в кВт·ч с десятичной точкой и не более чем тремя дробными знаками. Файл ограничен 128 КиБ и 500 записями. Номер строки сохраняется в отчёте.

Перед применением оператор сверяет распознанные строки. Дата проверяется по выбранной исторической установке, регистр — по конфигурации прибора. После подтверждения строки передаются существующей операции признания. Результат фиксируется для каждой строки. Повтор совпадающего показания возвращает прежнюю запись, конфликтующее значение отклоняется, запоздалое оценивается по соседним датам. Коэффициент применяется при расчёте потребления по установке. Из файла сохраняется исходное значение без умножения.

Чтение и запись ограничены сообществом. Применение требует действующего допуска и защиты CSRF. Признанное показание сохраняет источник импорта, основание и ссылку на допуск. Подключение внешних систем, импорт воды, исправление ранее признанных значений и эксплуатационные назначения рассматриваются отдельно.
