# I‑2. Контрольная сверка объёмов воды

Для заданных двух дат сравниваются объём каждой общей точки и сумма объёмов её непосредственных дочерних точек. Объём определяется разницей признанных граничных показаний в м³. Если показания отсутствуют хотя бы у одной точки ветви, разница по ней недоступна; пропуски видны по точкам.

Используется дерево, действовавшее на начальную дату. При смене версии строго внутри интервала требуется разбить его по границе изменения. Версия на конечную дату применяется к следующему интервалу. Сверка доступна по существующему праву чтения воды и не проводит финансовых операций.
