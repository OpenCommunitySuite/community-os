# I‑5. Печатная выписка по лицевому счёту

Бухгалтер выбирает лицевой счёт и формирует выписку по непогашенным обязательствам. Выписка содержит сообщество, счёт, дату сверки по Киеву, плательщиков, виды начислений, сроки и текущие остатки. Итог и просрочка сверяются с реестром задолженности.

Выписка использует действующий финансовый доступ сообщества и те же остатки, что реестр. Она отражает состояние на момент загрузки данных. Печать выводит только выбранный счёт. Формализация кассовых документов и передача выписки получателю относятся к отдельным сценариям.

Кнопка с номером счёта в реестре задолженности открывает выписку и переводит фокус на выбор счёта. Фильтры реестра действуют только на список задолженности. Выписка включает все непогашенные обязательства выбранного счёта.

Из детализации сверки периода можно открыть выписку того же счёта с обновлёнными остатками. Для полностью погашенного счёта выписка показывает нулевой долг. Выбор периода и фильтр детализации сохраняются.

Из истории распределений платежа бухгалтер может открыть выписку по счёту, на который была зачтена сумма. Выбранный платёж сохраняется. Выписка показывает текущий долг этого счёта, включая нулевой остаток после полного погашения.

В истории перераспределений доступны выписки по исходному и целевому счетам. Если оба обязательства относятся к одному лицевому счёту, обе кнопки открывают его выписку.
