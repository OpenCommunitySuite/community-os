# I‑5. Выгрузка начислений для внутренней сверки

Бухгалтер выгружает сводку проведённого периода в CSV. Файл содержит границы периода, лицевые счета, виды начислений, исходные и действующие суммы, разницу и общий итог. После подтверждённого перерасчёта новая выгрузка совпадает с текущей таблицей.

Выгрузка использует данные, уже доступные по праву финансового чтения сообщества. Имена плательщиков и платёжные реквизиты в файл не включаются. Формат использует UTF‑8 с BOM, разделитель «точка с запятой» и десятичную запятую. Текстовые поля экранируются, а потенциальные формулы в номерах счетов сохраняются как текст.
