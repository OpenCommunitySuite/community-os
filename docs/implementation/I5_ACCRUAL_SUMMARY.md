# I‑5. Сводка начислений за проведённый период

Бухгалтер открывает проведённый регулярный период и сверяет исходные и действующие суммы по электроэнергии и членским взносам. Сводка показывает итоги и разбивку по лицевым счетам, включая разницу после перерасчёта.

Источники — снимок проведённого периода для членских взносов и действующие обязательства для электроэнергии. Сводка использует существующий финансовый доступ сообщества. Разовые начисления ведутся отдельно. Проверка охватывает исходный итог, перерасчёт, повторное открытие периода и отказ доступа к чужому сообществу.
