# I‑5. Выгрузка задолженности для внутренней сверки

Бухгалтер выгружает текущую выборку реестра с учётом номера счёта и фильтра просрочки. CSV содержит дату сверки по Киеву, номер счёта, вид обязательства, срок, остаток, признак просрочки и итоги. Пустая выборка содержит нулевые итоги.

По BP‑TRANS‑001 выгрузка предназначена для внутренней сверки. Используются существующие финансовые данные выбранного сообщества. Имена плательщиков и реквизиты исключены. Формат и экранирование совпадают с другими финансовыми выгрузками.
