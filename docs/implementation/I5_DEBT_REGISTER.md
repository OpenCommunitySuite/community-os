# I‑5. Внутренний список задолженности

Бухгалтер открывает список непогашенных обязательств своего сообщества, видит общую и просроченную сумму, фильтрует по лицевому счёту и может оставить только просроченные строки. Срок, совпадающий с текущей датой Киева, ещё не просрочен. После частичной оплаты обновление показывает оставшуюся сумму, а погашенная строка исчезает.

Список использует действующие остатки и серверную дату из рабочего места платежей. Итоги складываются в копейках по показанным строкам. Нераспределённые платежи и авансы влияют на долг после подтверждённого зачёта. Доступ наследуется от существующего финансового чтения выбранного сообщества согласно ADR‑006 и BP‑TRANS‑001.

Фильтр по виду начисления применяется вместе с номером счёта и просрочкой. Таблица, итоги и CSV используют одну выборку. Переход из выписки сбрасывает вид и просрочку, чтобы показать все долги выбранного счёта.
