# I‑5. Выгрузка сводки поступлений

Бухгалтер скачивает CSV для внутренней сверки. Выгрузка повторяет выбранный диапазон дат получения, количество и действующие суммы признанных платежей по трём источникам и текущий нераспределённый остаток. Детализация содержит дату, источник и суммы каждого платежа. Основания, имена и реквизиты остаются в рабочем интерфейсе.

Файл использует существующий финансовый доступ сообщества согласно BP‑TRANS‑001. Для сверки проверить границы периода, исправление платежа, исключение непризнанной строки банка и совпадение файла с экранными итогами.
