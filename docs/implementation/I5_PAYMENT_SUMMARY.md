# I‑5. Внутренняя сводка поступлений

Бухгалтер выбирает диапазон дат получения включительно и сверяет количество признанных платежей и их действующие суммы отдельно по банку, кассе и ручной регистрации. Итог и детализация строятся по одним строкам. Исправление суммы отражается после обновления.

Сводка использует существующее право финансового чтения сообщества. Согласно BP‑TRANS‑001 отчёт предназначен для внутренней сверки. Банковская строка учитывается после признания платежа, а распределения, авансы и кассовые факты не добавляют повторных поступлений. Свободный остаток показан как текущий, без реконструкции состояния на конец диапазона.

Фильтр по плательщику работает совместно с датами. Выбор учитывает идентификатор плательщика, включая совпадающие имена. Таблица, итоги и CSV используют одну выборку. Имя и идентификатор плательщика в CSV не включаются.
