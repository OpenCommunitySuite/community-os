# I‑5. Сверка проведённого периода

Бухгалтер открывает проведённый период и запрашивает текущую сверку по электроэнергии и членским взносам. По каждому виду сверка показывает действующую сумму, зачтённую в пределах начисления оплату, непогашенный остаток и отдельно излишне применённую сумму. Начисление равно зачтённой оплате плюс долгу. Излишне применённая сумма сама по себе не означает признанную переплату.

Данные берутся из действующих обязательств в одной транзакции с существующим финансовым доступом сообщества. Сверка показывает текущее состояние обязательств выбранного периода независимо от даты платежа. Разовые начисления и свободные платежи сюда не входят.

Детализация показывает обязательства по лицевым счетам из той же выборки, по которой рассчитаны итоги. Фильтр счёта действует на детализацию. Сводка сохраняет итог по всему периоду. Для номера счёта используется снимок проведения периода, как в сводке начислений.

CSV для внутренней сверки содержит границы периода, итоги по видам и по всему периоду, а также строки текущей детализации. Итоги и детализация помечены отдельно. Формат и экранирование совпадают с остальными финансовыми выгрузками. Доступ наследуется от просмотра сверки.
