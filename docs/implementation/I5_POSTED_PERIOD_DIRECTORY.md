# I‑5. Список проведённых периодов

Бухгалтер загружает список проведённых периодов, видит даты потребления, срок оплаты и время проведения. Из строки можно открыть сохранённый расчёт и перейти к сверке без ручного ввода дат.

Список читается из реестра проведённых периодов по действующему финансовому доступу сообщества. Проверка охватывает порядок, пустой список, открытие нужного периода и изоляцию сообществ.
